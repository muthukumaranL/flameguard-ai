# FlameGuard AI - runtime dependencies for the deployed Streamlit app.
#
# Streamlit Community Cloud installs from this file, so it stays lean: only what
# app.py imports at runtime. Analysis, export, document and test tooling lives in
# requirements-dev.txt, which scripts/setup_environment.sh (.bat) installs.
#
# torch/torchvision are intentionally NOT pinned here. ultralytics pulls them in,
# and the Cloud installed them without trouble. Pinning the +cpu wheels needs an
# --extra-index-url, which resolvers treat inconsistently (uv's default
# first-index strategy never reaches the extra index for a +cpu local version),
# so an explicit pin is more fragile here, not less. Locally,
# scripts/setup_environment.* installs the CUDA wheel before this file is read.

# Core inference
ultralytics>=8.3,<9
opencv-python>=4.10   # imports cv2, which needs libgl1 - see packages.txt

pandas>=2.2

# Application
streamlit>=1.40
